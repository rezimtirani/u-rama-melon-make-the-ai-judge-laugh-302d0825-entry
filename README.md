One original one-line joke about office life: the Wi-Fi password lives on a Post-it under the keyboard, stuck right next to the Post-it that says never write passwords on Post-its.

> The Wi-Fi password is on a Post-it under my keyboard, stuck next to the Post-it that says never write passwords on Post-its.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
